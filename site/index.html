All Media Downloader

Save every photo on a social media profile. Use the website for Reddit, Tumblr, Pinterest and about 300 other sites, or the Chrome extension for Instagram and X, which only work with your own login.

Which one to use

Instagram, X profilesExtension. These sites block servers and need your login, which only your browser has.
Instagram, X, TikTok, Facebook postsEither. Paste up to 50 post links into the website, or open a post and use the extension.
Reddit, Tumblr, PinterestEither. The website gives you a ZIP. The extension saves straight to your Downloads folder.
Flickr, Imgur, DeviantArt and moreWebsite. It supports every site gallery-dl handles. The extension also works on most photo sites by scrolling the page.

The website

Paste one profile link, or up to 50 post links (one per line), wait while the server collects the photos, then download the ZIP. It's password protected because it's a private tool. Files are deleted from the server an hour after each download.

The Chrome extension

Download the extension (.zip)

  1. Unzip it somewhere you'll keep it, like your Documents folder.
  2. In Chrome, go to chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and pick the unzipped all-media-downloader-extension folder.
  4. Open a profile, for example instagram.com/natgeo or x.com/NASA/media, or a single post, then click the extension's icon and press Save photos.

Photos go to Downloads/AllMediaDownloader/<site>_<profile>/. If Chrome asks where to save every file, turn off "Ask where to save each file" in Chrome's download settings. To update, download the new ZIP, replace the folder, and press the reload arrow on the extension's card.

Why two tools

Instagram and X block downloads from cloud servers and hide most content from logged-out visitors. The extension runs in your browser, so requests come from you, with your login, at a polite pace. Only accounts you can already see are reachable.
